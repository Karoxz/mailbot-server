How the web bot works

Web bot and desktop app take turns automatically. You can connect the same Gmail account to both. While the desktop app is running (after START) the web bot pauses by itself and shows "paused — desktop running"; about a minute after you stop the desktop, the web bot takes over again. They never run at the same time, so they can't fight over the same emails.

Turning the web bot ON does what the desktop's START does: Telegram notifications and thread learning are switched on, you get a "Watching" message, and the last 2 days of unread freight mail are scanned once. Gmail itself is connected on the Settings page.
